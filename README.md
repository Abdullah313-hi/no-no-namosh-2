# Finding No-No-Namosh II: The Lost Star

Playable Part 2 development build.

## Included in this build
- English / Swedish language selection
- Opening apartment sequence with Namosh and the kittens
- Rosewood rain sequence
- Greenhaven Valley exploration
- Abdullah companion/follower system
- Star Fragment mystery
- Sami the Fisherman swimming lesson
- Swimming and current traversal
- Crystalwater Grotto dungeon
- Floodgate progression
- Diving unlock and underwater passage
- Five-Point Star reveal
- Save/continue with localStorage
- Keyboard and touch controls

## Controls
- Move: Arrow keys / WASD / on-screen D-pad
- Interact: Enter / Space / A button
- Dive/surface once unlocked: B
- Inventory: I / BAG

## GitHub Pages
For the simple GitHub Pages build, upload only `index.html` and `README.md` to the repository root. The `index.html` file is fully standalone and contains the game, styles, translations, and scripts. Enable Pages from `main / root`.


## New character & dialogue presentation
- Important speakers now use large retro pixel-art dialogue portraits above the text box.
- Dr. Cassian Vale has been replaced in Part II canon by **Dr. Meow Skuttan**, a grey British Shorthair scholar-adventurer with round glasses and a tiny explorer satchel.
- Skuttan now makes early appearances in Greenhaven and Crystalwater Grotto, setting up his larger role in the later Starstone story.
